Para agregar una imagen: copia el archivo con el nombre exacto indicado
en la carpeta correcta. El sitio la muestra automáticamente.
Si el archivo no existe → placeholder automático, el sitio no se rompe.

══════════════════════════════════════════════════════════════════════
IMÁGENES PRINCIPALES DEL SITIO  (carpeta: images/)
══════════════════════════════════════════════════════════════════════

  logo.png
  ├── Usado en: Navbar, Footer, Hero, About
  ├── Formato:  PNG con fondo transparente
  └── Tamaño:   400×150 px mínimo

  hero.jpg
  ├── Usado en: Sección Hero de la página principal (lado derecho)
  ├── Formato:  JPG o WebP
  └── Tamaño:   1200×900 px recomendado, máx 400 KB

  about.jpg
  ├── Usado en: Página About Us (lado izquierdo)
  ├── Formato:  JPG o WebP
  └── Tamaño:   900×700 px recomendado, máx 300 KB

Para cambiar estas rutas, edita src/data/data.json:
  "site": {
    "logo":        { "image": "/images/logo.png"  },
    "hero_image":  "/images/hero.jpg",
    "about_image": "/images/about.jpg"
  }

REGLA GENERAL
══════════════════════════════════════════════════════════════════════
  • El nombre del archivo debe coincidir EXACTAMENTE con el valor
    "image" en data.json (incluyendo minúsculas y guiones)
  • Si una imagen no existe → placeholder automático, sin errores
  • Para cambiar el nombre de un archivo, actualiza data.json también
